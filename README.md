# Dice Rolling Simulator Using Python

A simple and interactive Dice Rolling Simulator developed using Python and Tkinter. This application simulates rolling a six-sided dice and generates a random number between 1 and 6 whenever the user clicks the Roll Dice button.

## Features
- Simulates a six-sided dice.
- Generates random numbers between 1 and 6.
- Displays different dice faces.
- Interactive Roll Dice button.
- Shows the generated result instantly.
- User-friendly graphical interface.
- Exit button to close the application.

## Technologies Used
- Python
- Tkinter
- Random Module
- PyCharm
